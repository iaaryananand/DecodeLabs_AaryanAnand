# Week 1 Project — Data Cleaning with Excel

## Overview

This project uses Excel to clean and organize an e-commerce orders dataset for the Week 1 project provided by DecodeLabs.

The cleaned dataset contains order, customer, product, payment, shipping, and sales information. It is structured as a table with column headers and formatted values.

## Dataset Columns

| Column | Description |
|---|---|
| `OrderID` | Unique identifier for an order |
| `Date` | Date the order was placed |
| `CustomerID` | Identifier for the customer |
| `Product` | Product ordered |
| `Quantity` | Number of units ordered |
| `UnitPrice` | Price per unit |
| `ShippingAddress` | Order shipping address |
| `PaymentMethod` | Payment method used |
| `OrderStatus` | Current order status |
| `TrackingNumber` | Shipment tracking identifier |
| `ItemsInCart` | Number of items in the cart |
| `CouponCode` | Coupon applied to the order, if any |
| `ReferralSource` | Source through which the customer arrived |
| `TotalPrice` | Total value of the order |
