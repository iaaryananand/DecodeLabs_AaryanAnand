# Week 2 Project — E-commerce Sales Analysis in Excel

## Overview

I analyzed an e-commerce orders dataset using Microsoft Excel. The project explores sales, order status, payment methods, and monthly trends.

## Tools Used

- Microsoft Excel
- PivotTables
- Charts

## Analysis

I summarized order values, checked for potential outliers using the IQR method, and compared sales by product, order counts by status, average order value by payment method, and monthly sales.

## Key Findings

- The dataset contains 1,200 orders.
- Average order value was ₹1,053.97; the median was ₹823.62.
- Chair had the highest total sales, while Phone had the lowest.
- Order counts by status ranged from 231 Delivered to 250 Cancelled.
- Credit Card orders had the highest average order value at ₹1,127.55. This is an observed pattern and does not prove the payment method caused higher spending.
- The IQR check flagged 8 potential high-value outliers for review. They are not confirmed errors.
- Sales varied month to month. The 2025 data covers January through June only.
