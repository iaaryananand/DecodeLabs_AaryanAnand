# Week 2 Project — E-commerce Sales Analysis in Excel

## Overview

This project analyses an e-commerce orders dataset using Microsoft Excel to explore sales patterns, product performance, order status, payment methods, and monthly trends.

## Objective

The objective was to summarise the dataset, compare order and sales patterns, identify potential outliers, and present findings that could help support business analysis.

## Tools and Methods

- Microsoft Excel
- PivotTables
- Charts and data visualisation
- Descriptive statistics
- Interquartile Range (IQR) method for potential outlier detection

## Analysis Performed

- Summarised order values using descriptive statistics.
- Compared sales by product and order counts by status.
- Examined average order value by payment method.
- Analysed monthly sales trends.
- Used the IQR method to flag potential high-value outliers for review.
- Created summary tables, PivotTables, and a dashboard.

## Key Findings

- The dataset contains 1,200 orders.
- The mean order value was ₹1,053.97, while the median was ₹823.62.
- Chair had the highest total sales, while Phone had the lowest.
- Order counts by status ranged from 231 Delivered to 250 Cancelled.
- Credit Card orders had the highest average order value at ₹1,127.55. This is an observed association and does not establish causation.
- The IQR check flagged 8 potential high-value outliers for review. These are not confirmed errors.
- The 2025 data covers January through June only, so monthly comparisons should be interpreted within that period.
