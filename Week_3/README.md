# Week 3 — E-commerce Sales Analysis with SQL

## Overview
I analyzed an e-commerce orders dataset using Microsoft SQL Server and SQL queries.

## Tools Used
- Microsoft SQL Server Management Studio
- SQL

## Analysis
I wrote queries to:
- Count orders and calculate total and average sales
- Compare sales by product
- Count orders by status
- Compare average order value by payment method
- Find the 10 highest-value orders above 3,000
- Summarize sales by month and year
- Compare sales by referral source

## Key Findings
- The dataset contains 1,200 orders.
- Total sales were ₹12,647,761.96.
- Chair had the highest total sales among the products.
- Credit Card orders had the highest average order value.
- Instagram had the highest sales among the referral sources.
- The 2025 data covers January through June only.
