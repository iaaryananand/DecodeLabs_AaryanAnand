# Week 3 Project — E-commerce Sales Analysis with SQL

## Overview
This project analyzes an e-commerce orders dataset using Microsoft SQL Server. I used SQL queries to summarize sales and explore patterns by product, order status, payment method, month, and referral source.

## Objective
The objective was to practise SQL data analysis and use query results to identify useful patterns in the orders dataset.

## Tools and Methods
- Microsoft SQL Server Management Studio
- SQL
- `SELECT`, `WHERE`, `ORDER BY`, and `GROUP BY`
- `COUNT`, `SUM`, and `AVG`

## Analysis Performed
- Calculated the number of orders, total sales, and average order value.
- Compared order counts and sales across products.
- Counted orders by status.
- Compared average order value across payment methods.
- Listed the 10 highest-value orders above ₹3,000.
- Summarized sales by month and year.
- Compared sales across referral sources.

## Key Findings
- The dataset contains 1,200 orders.
- Total sales were ₹12,647,761.96, and the average order value was about ₹1,053.97.
- Chair had the highest total sales among the products; Phone had the lowest.
- Credit Card orders had the highest average order value, about ₹1,127.55. This is an observed pattern and does not prove that the payment method caused higher spending.
- Instagram had the highest total sales among the referral sources.
- Monthly sales varied. The 2025 data covers January through June only.

## Project Files
- `Week_3_Sales_Analysis.sql` — SQL queries used for the analysis.
- Query screenshots — screenshots showing the queries and their results.
- `orders.csv` — dataset imported into SQL Server.

## Conclusion
This project gave me practice importing a CSV dataset into SQL Server, writing SQL queries, and using query results to explore e-commerce sales patterns.
